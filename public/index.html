Memspace users demo

A small Express API whose only storage is memspace-fs, an in-memory filesystem with the Node fs API. Every user you add becomes a file at /users/<id>.json in memory. Nothing touches the disk. Each user expires after an hour (a memspace TTL), storage is capped at 5 MiB, and everything resets when the server restarts.
